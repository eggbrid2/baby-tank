## 已知边界

1. 上游资料确认触摸通道 1 为顶部、2/3 为两侧，但没有明确标注 2/3 的物理左右。目前暂按 2=左、3=右，需实摸观察眼睛方向；若反向只交换映射。
2. 未连接云 Wi-Fi 时，侧触摸仍有注视动画，但主动语音会被拒绝，这是预期行为；完整主动语音必须先完成家庭 Wi-Fi 配网。
3. Debug APK 中的测试秘密可被逆向提取。个人单机联调可以接受，公开分发或量产不可沿用。
4. 扫描 Wi-Fi 需要 Android 的附近设备/位置权限，系统可能要求开启定位服务；这是 Android 平台限制，不等于 App 上传位置。
5. 运动摇杆和急停仍保持禁用，因为底盘固件、能力握手和 500 ms 独立失联停车尚未验证。

## 真机测试顺序

1. 安装 APK，授予附近设备与 Wi-Fi 扫描权限。
2. 在“连接”页扫描并选择 `BabyTank-694968`，点“连接设备”。
3. 确认 Wi-Fi 名称自动填入；必要时点“扫描 Wi-Fi”，输入密码后点“连接 Wi-Fi”。
4. 顶部触摸验证进入聆听；左右各触摸一次，核对眼睛是否朝手指方向看。
5. 联网后再次侧触，验证设备主动生成一句符合机器人宝宝人格的语音。
6. 在“遥控”页点“连接摄像头”，接受 Android 的系统 Wi-Fi 连接确认，检查视频帧率和断线重连。

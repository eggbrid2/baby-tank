# Android 遥控模式、AI 隔离与开炮动画记录

日期：2026-10-17

## 目标

- 手机进入遥控页时播报“已进入遥控模式”。
- 遥控期间停止 WakeNet、触摸对话、云端 ASR/LLM/TTS、AI 自主移动和正在进行的语音会话。
- 离开遥控页后恢复本地唤醒；App 异常退出或蓝牙断开时也不能永久停用 AI。
- “开炮”同时触发停车、炮声和头部屏幕的漫画爆炸动画。
- 所有 BLE 自定义端点请求串行化，避免 Espressif Security1 会话并发导致 `Key mismatch`。

## 实现

### 遥控租约

Android 遥控页每 2 秒通过加密 `baby-diagnostics` 端点发送一次遥控租约。固件租约为 5 秒：

- 第一次进入时取消当前云端请求和播放，停止 AI 自主运动及底盘，关闭 WakeNet，并播放内置 16 kHz、16-bit、单声道 PCM“已进入遥控模式”。
- 租约续期只更新时间，不重复播报。
- 正常退出立即发送关闭命令并恢复 WakeNet。
- App 崩溃、被强杀或 BLE 断开时，5 秒超时自动恢复 WakeNet。

诊断协议 v1 新增：

- opcode `6`：参数 `1` 为进入/续租，`0` 为退出。
- 响应 byte `11`：当前遥控模式状态。

### 顶部触摸切换对话

顶部触摸由单向“开始聆听”改为切换：空闲时进入对话，已经处于聆听、思考或播放时再次触摸会取消云端请求、停止播放、清空待处理请求并恢复 WakeNet。遥控租约有效时，触摸不会启动 AI。

### BLE 请求串行化

控制握手、底盘运动、诊断、灯光、声音、摄像头信息和热点切换共用一个进程内 FIFO。运动请求额外带修订号，旧的排队方向会被丢弃，释放按键后的 STOP 或最新方向优先。该修改针对实机出现的 Security1 `Invalid state` / `Key mismatch`，不是 UI 层重试。

### 漫画开炮效果

新增诊断 opcode `7`，固件原子执行：

1. 播放程序生成的炮击声；
2. 发送底盘 STOP；
3. 以安全级优先级播放 1.7 秒 `cannon` 屏幕动作。

屏幕动画保持黑底，依次包含蓄力准星、珊瑚红/青色/奶油色冲击环、屏幕震动、放射火星和上升烟团；不使用整屏白闪。功能检测页也可单独播放“开炮爆炸”动画。

声音编号已明确分离：`0` 汽车喇叭、`2` 程序炮声、`3/4` 应答语、`5` 让路语音、`6` 遥控模式播报。该映射必须保持，否则遥控进入提示会错播成让路语音。

## 实机证据

- 固件 `baby_tank_head 0.13.18` 在 ESP32-S3（16 MiB Flash、8 MiB Octal PSRAM）启动成功。
- 最终 app-only 镜像 SHA-256：`54083afedbdeb0aa7bc4d0ca7fdb456079975b306e4f923d541ecbea1160597c`。
- Android `0.1.1`（versionCode 2）测试包 SHA-256：`ff14b4e8373261fe54b1bb2122bfced63cef621e48a3a11f0f9295c73b3333fa`。
- App 进入遥控页后日志出现 `remote mode entered; AI and WakeNet paused`。
- 最新音频编号修正后日志出现 `embedded clip played: 已进入遥控模式 3197 ms`，确认没有错播成让路语音。
- 摄像头在遥控模式持续出流。
- 单次前进按住/释放曾得到连续 `left=600 right=600 status=0`，随后 `BLE stop ... status=0`；自动化横屏坐标不再用于运动回归，以免旋转映射误触。
- 连续灯光、声音和摄像头请求期间未再次观察到 Security1 `Key mismatch`。
- App 被强制停止后日志出现 `remote mode lease expired`，随后 `remote mode exited; WakeNet restored`。
- 开炮命令日志出现 `active emotion=cannon intensity=100 duration_ms=1700 priority=100`，并在结束后返回 `calm`。

## 尚需人工确认

- 屏幕爆炸动画的节奏、颜色和“冲击感”需要以实物肉眼评价，日志只能证明帧状态机被执行。
- 炮声及遥控提示语的主观音量、音质需要人耳确认。
- 右侧触摸仍有已知误触，当前未把左右触摸接入云端对话。
- 方向控制必须继续在空旷地面由人手测试；ADB 横屏坐标受系统旋转映射影响，不能作为安全运动验收手段。

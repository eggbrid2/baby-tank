# 手机画板「猜猜我画的」

日期：2026-10-22

## 交互

- 入口：Android App → 互动 → 猜猜我画的。
- 孩子在大尺寸手机画板自由画线，底部只保留一个居中的「让它猜」。
- 云端视觉模型只返回 1–12 个字符的中文物体名；App 立即展示猜测，头部通过现有长连接播报「我猜这是……」。
- 猜错后保留原画，可继续添画；每局最多三次猜测。结果页只要求孩子判断「猜对了 / 你猜错了」：点「你猜错了」后，头部立即播放本地失败短句并显示失落表情，不走云端 TTS；答对后的下一局入口命名为「再画一个」，不再显示含义模糊的「重新开始」。
- 「猜猜我画的」菜单入口和「让它猜」主按钮共用经用户确认的生成插画：宝宝坦克观察画纸并冒出问号。按钮本体仍由 Compose 绘制粗描边、下沉底座和按压位移，保证触摸反馈清楚，图片本身不承载文字。
- 顶部不显示轮次和玩法说明；离开画板即清空本局，下次进入从空白画布开始。
- 游戏不会开启设备聆听、摄像头或底盘动作，也不会触发 AI 绘画。

## 数据与资源边界

- App 将画板归一化为 384×384 JPEG，单次上限 96 KiB。
- 云端校验 JPEG、像素尺寸、有效笔迹面积和请求频率；空白图在视觉请求前拒绝。
- 草图只在当前请求内存中使用，不写 SQLite、对话记忆或问题记录。审计仅记录轮次、猜测文字和归一化字节数。
- 猜测只调用一次 `qwen3-vl-plus`。播报使用固定句式，不再调用普通对话模型；该游戏轮次也不改变长期心情。

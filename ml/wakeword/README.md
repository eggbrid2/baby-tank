# 自定义本地唤醒模型备用方案

状态：暂停。产品唤醒词已于 2026-10-16 改为“喵喵同学”，首版采用 ESP-SR 自带的 WakeNet9 模型 `wn9_miaomiaotongxue_tts`，不需要训练新模型。

本目录保留为现成 WakeNet 模型实测不达标时的备用自训、评测和发布位置。目标运行环境是 ESP32-S3 N16R8，备用推理引擎是 TensorFlow Lite Micro，训练框架首选 microWakeWord。

## 已暂停的旧方案

- 原唤醒词：宝宝坦克
- 模型 ID：`baobao_tanke_v1`
- 主发音：`bǎo bao tǎn kè`，第二个“宝”为自然轻声
- 兼容发音：`bǎo bǎo tǎn kè`
- 输入：16 kHz、16-bit signed PCM、mono
- 预期输出：INT8 流式 `.tflite` 模型和带阈值的版本化 manifest

没有完成或发布过该自训模型；不能把本目录的目标指标当成实测结果。

## 数据集边界

正样本需覆盖男女成人、儿童、近场/远场、快速/正常/慢速、轻声和完整三声变体。TTS 样本用于扩大声线和速度，家庭成员真人录音用于校正真实发音。

困难负样本至少包含：

- “宝宝”、“坦克”、“抱抱”、“宝宝看看”、“宝宝打开”；
- 普通家庭对话、电视/短视频、音乐、玩具声和孩子尖叫；
- Baby Tank 自身 TTS 回答、启动音和电机噪声；
- 不同距离和不同信噪比下的近音词。

语音原始数据不纳入 Git；仓库只保存可重现配置、数据来源/许可清单、模型、manifest、SHA-256 和聚合评测结果。儿童录音必须经监护人同意，默认不上传第三方。

## 首版验收门槛

以下是工程目标，不是当前已达成的数字：

- 安静环境召回率 `>= 95%`；
- 常见家庭噪声下召回率 `>= 90%`；
- 误唤醒 `<= 1 次 / 8 小时`；
- 唤醒词结束后检测延迟目标 `<= 500 ms`；
- 机器人自身 TTS 连续播放 100 轮不得触发唤醒；
- 8 小时连续运行无看门狗、内存泄漏或显示卡顿。

未达标模型不进入生产固件，也不能因为少量现场演示成功就标记为“完成”。
